# README 展示素材

这些图片用于仓库首页展示，不是评测报告或商业案例。

| 图片 | 来源与范围 |
|---|---|
| `avatar.png` | 维护者提供并指定使用的女孩图片，裁切为头像尺寸并添加圆角；不纳入项目源码的 MIT 授权范围。 |
| `customer-overview.jpg` | 公开源码离线演示实例的客户首页。 |
| `customer-ticket.jpg` | 同一离线实例的已关闭工单及完整时间线。 |
| `knowledge-management.jpg` | 同一离线实例的管理员知识目录。 |
| `staff-workbench.jpg` | 同一离线实例的客服工单工作台。 |
| `service-login.jpg` | 同一离线实例的登录页，使用公开版抽象 SVG 背景。 |
| `ai-answer-with-citation.jpg` | 已保存的真实模型回答及展开的来源引用；本次截图整理没有新增模型调用。 |

设备、订单、联系人与知识资料均为合成演示数据。离线实例的页面保留运行模式提示，不作为真实 AI 回答质量的证据。

`*-preview.jpg` 为画廊缩略图，保持原始比例，以浅色留白统一尺寸；客户工单缩略图只裁切处理时间线区域。点击 README 中的预览图可打开完整截图。图片未修改页面文字、数字或业务结果。
